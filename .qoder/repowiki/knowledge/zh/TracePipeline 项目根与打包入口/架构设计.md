本模块为顶层聚合层，不承载业务逻辑，仅暴露两个运行入口：`run_trace_pipeline.py` 调用 `trace_pipeline.cli.main` 提供命令行批处理；`run_gui.py` 在 Windows 上通过 ctypes 调用 user32 API 设置 Per-Monitor V2 DPI 感知、强制 matplotlib 使用 Agg 后端后启动 `backend.main_gui.main`（基于 pywebview 的 GUI）。`pyproject.toml` 定义包名 `trace-pipeline`、Python ≥3.10 约束、`trace_pipeline` 与 `backend` 两个发现包，并通过 `[project.scripts]` 注册 `trace-pipeline` CLI 命令指向 `trace_pipeline.cli.main:main`。`requirements.txt` 由构建系统从 `pyproject.toml` 同步生成（头部注释明确禁止手动编辑）。`TracePipeline.spec` 是 PyInstaller 打包规格，显式声明 `hiddenimports` 以覆盖 `matplotlib.backends.backend_agg`、`webview.platforms.*`、`scipy.*` 以及 trace_pipeline 子包的惰性导入路径，最终产出 `dist/TracePipeline/` 独立文件夹。`config.example.json` 提供所有可配置项模板，被 `trace_pipeline.config.ensure_workspace_dirs` 等模块消费。
